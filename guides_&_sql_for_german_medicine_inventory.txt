🔵SQL Section 🟢And basic guild inside PiostgrSQL

View the full table⬇️

SELECT * FROM sales_business.german_medicine_inventory

🔵 This will retrieves all records from the table and sorts them from the lowest to the highest retail_price
Just change the column name.⬇️

SELECT * 
FROM sales_business.german_medicine_inventory
ORDER BY retail_price ASC;

🔵 Find any medicine you think that is inside the table⬇️

SELECT * 
FROM sales_business.german_medicine_inventory
WHERE medicine_generic_name LIKE 'f%';


🟢Type the first letter of the name of the medicine you want to search for (beside the %). [With lowercase letters]
If there is no medicine with that letter, you will see this message.👇
